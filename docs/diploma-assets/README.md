# Fastik Diploma Assets

Папка содержит материалы, которые можно приложить к дипломной работе или использовать при написании практической части.

## Состав

- `ERD.mmd` — ER-диаграмма базы данных в формате Mermaid.
- `PROJECT_STRUCTURE.md` — структура проекта без `node_modules`, `dist` и служебных директорий.
- `SQL_SCHEMA.sql` — SQL-схема, собранная из миграций `backend/src/db/migrations`.
- `OPENAPI.json` — Swagger/OpenAPI спецификация Fastik API.
- `screenshots/` — скриншоты интерфейса.

## Swagger

При запущенном backend Swagger UI доступен по адресу:

```text
http://localhost:4200/docs
```

JSON-спецификация доступна по адресу:

```text
http://localhost:4200/openapi.json
```
